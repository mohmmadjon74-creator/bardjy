# نظام البردجي لإدارة الفروع

تطبيق عربي يعمل مباشرة دون حسابات أو اتصال بخادم. تُحفظ بيانات العمل في قاعدة IndexedDB داخل المتصفح وعلى الجهاز نفسه. تتضمن النسخة الحالية لوحة الفروع، الزبائن، الطلبات، الدفعات، المصاريف، المخزون، وملخص التقارير.

## التشغيل والتخزين

افتح `index.html` في المتصفح. عند التشغيل الأول ينشئ النظام قاعدة بيانات محلية باسم `al-bardaji-local` ويضيف الفروع الثلاثة تلقائياً. يبدأ تخزين الزبائن والطلبات والدفعات والمصاريف والمخزون على هذا الجهاز فقط، وتبقى بعد إغلاق المتصفح وإعادة تشغيل الجهاز، ما دامت بيانات الموقع لم تُحذف.

يمكن تعديل بيانات الزبون أو حذفها من عمود الإجراءات في صفحة سجل الزبائن. يُمنع حذف الزبون المرتبط بطلبات مسجلة حفاظاً على سجل الطلبات.

تعرض لوحة التحكم تفاصيل السجلات والإجماليات عند الضغط على أي بطاقة إحصائية.

تتكيّف الواجهة مع شاشات الهاتف، بما في ذلك قائمة اختيار الفرع والجداول القابلة للتمرير أفقياً عند الحاجة.

كل متصفح/ملف مستخدم يحتفظ بنسخته المنفصلة؛ البيانات لا تنتقل تلقائياً إلى جهاز آخر أو إلى الفروع الأخرى. لا توجد حالياً ميزة تصدير أو استعادة نسخة احتياطية داخل التطبيق. تجنب وضع التصفح الخاص، ولا تمسح بيانات الموقع؛ فقد يؤدي ذلك إلى حذف قاعدة البيانات المحلية نهائياً.

## حدود النسخة الحالية

هذه نقطة أساس تشغيلية. القياسات التفصيلية، تحرير مراحل العمل، طباعة/PDF الفواتير، الموردون والمشتريات، خصم القماش تلقائياً من المخزون، النسخ الاحتياطي/الاستعادة من داخل التطبيق، تقارير الفترات التفصيلية، وإشعارات مواعيد التركيب تحتاج مراحل تنفيذ لاحقة. تقارير الربح الحالية لا تمثل إقفالاً محاسبياً أو اعتماداً ضريبياً.
